# Design systems

24 complete design systems from the Codex Design library. Each DESIGN.md has colors for light and dark mode, Google Fonts, a type scale, radius, spacing, layout or app rules, and do's and don'ts. Every text color passes WCAG contrast.

- Live previews: https://codexdesign.io/design-systems/<slug>
- Plain DESIGN.md: https://codexdesign.io/design-systems/<slug>.md
- shadcn theme: `npx shadcn@latest add https://codexdesign.io/r/<slug>.json`
- All files on GitHub: https://github.com/ummydev/design-md

## How to pick three

1. Filter by platform: web systems for pages and web apps, app systems for phone screens.
2. Keep the ones whose "For" column fits the product's world, then choose three that differ in mode (light or dark), type (serif, grotesque, condensed) and density.
3. Prefer a system the product's audience would recognize as theirs over one that is merely fashionable.
